# 番号配置アプリ

図面(PDF・画像)の上に、〇付きの通し番号と矢印を配置するデスクトップアプリです(Python / Tkinter)。
配置した注記は編集可能なまま保存でき、必要なときだけ画像(PNG)として書き出せます。

Windows 用のアプリ(exe)のほかに、**iPad・Android・パソコンのブラウザで使える Web版**があります。
2つは同じ編集ファイル(`.annot`)を読み書きできるので、Win版で付けた注記を iPad で直す、またはその逆ができます。

## どちらを使う?

| | exe版(Windows) | Web版(ブラウザ) |
| --- | --- | --- |
| 向いている端末 | Windows のパソコン | iPad・Androidタブレット/スマホ・Windows/Mac のパソコン |
| 入れ方 | exe をダウンロードして実行(Python不要) | URL を開くだけ(インストール不要。ホーム画面に追加するとアプリのように使えます) |
| 操作 | マウス | 指・ペン・マウス |
| 図面・編集ファイルの置き場所 | パソコンのフォルダ(編集ファイルに図面の場所を記録) | 端末のファイル(図面は編集ファイルと一緒に選んで開く) |
| 大きな図面 | そのまま扱える | 端末の上限に合わせて、表示用の画像だけ縮小(座標は元のまま) |
| PNG書き出し | 保存先を選ぶ | ダウンロード / 共有(iPad は「写真に保存」も可) |

どちらも、図面の追加・ページの入れ替え・表の表示切り替えができ、**同じ編集ファイル(`.annot`)を読み書き**できます。
編集ファイルは version 3 の形式です(version 2 以前の古い編集ファイルは読み込めません。詳しくは [docs/FORMAT.md](docs/FORMAT.md))。

## Web版(iPad・ブラウザ)

`web/` フォルダの中身が、そのままWebアプリです(GitHub Pages で公開します)。

- 公開後のアドレス(目安): `https://kouichi-m-source.github.io/Number-placement-app/`
- **iPad**: Safari で開き、共有ボタン → **「ホーム画面に追加」** を選ぶと、アプリのように全画面で使えます(一度開けば、オフラインでも使えます)
- **Android**: Chrome で開き、メニュー(︙)→ **「アプリをインストール」または「ホーム画面に追加」**
- **Windows / Mac のパソコン**: Chrome や Edge で開くだけで使えます(アドレスバーの「インストール」で、アプリのように起動もできます)。Windows にはexe版もあります
- 動作確認は、パソコンの Chrome と iPad(Safari)を想定しています。Android は同じ仕組みで動く見込みですが、実機での確認はまだです
- 縦持ち・横持ちのどちらでも使えます(縦持ちは図面が上、表が下に並びます。境界をドラッグして高さを変えられます)

### 公開のしかた(初回だけ)

1. GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** にする
2. `main` に `web/` の変更が入ると、自動で公開されます(`.github/workflows/pages.yml`)。手動で公開するときは、**Actions → Deploy web app → Run workflow**

### exe版とWeb版の更新のしかた

| | 何をするか |
| --- | --- |
| Web版 | 変更を `main` に取り込む(マージする)だけ。**リリースは不要**です。自動で公開し直され、ブラウザで開き直すと(ホーム画面のアプリは一度閉じて開き直すと)新しくなります |
| exe版 | 変更を `main` に取り込んだあと、GitHub の画面で**新しいリリースを作る**(タグ `V1.0.x`)。exe が自動でビルドされて添付されます |
| 両方 | 変更を `main` に取り込む → Web版は自動で公開、続けてリリースを作ると exe版も更新、の順 |

### Web版の操作

| 操作 | 内容 |
| --- | --- |
| 空いている所を**ダブルタップ**(ダブルクリック) | 新しい番号を配置(2回目を押したままドラッグで矢印の向き) |
| 〇・矢印の先の ● をドラッグ | 移動 / 矢印の向きと長さ |
| **長押し**(マウスは右クリック) | メニュー(矢印を追加・削除。空いている所なら「ここに新規配置」)。表の行でも同じ |
| 1本指で空いている所をドラッグ | 画面の移動 |
| 2本指のピンチ(Ctrl+ホイール) | 拡大縮小 |
| 表の行をタップ → もう一度そのセルをタップ | セルの編集(共通OFFの行の、文字・長さ・太さ・色。番号と角度はいつでも) |
| 「共通」「矢印」列のタップ | ON・OFFの切り替え |

- **開く**: 「開く」で、図面(PDF・画像)も編集ファイル(.annot)も開けます。編集ファイルは**図面と一緒に選ぶ**と一度に開けます(編集ファイルだけ選ぶと、図面を聞かれます)
- **追加**: 「追加」で、開いている作業(編集ファイルを開いたあとも)の**最後のページの後ろ**に、図面(PDF・画像)を足せます。複数まとめて選べます。編集ファイルは追加できません
- **ページの入れ替え**: 「編集」→「ページの入れ替え」。▲▼か、左の ≡ のドラッグで並べ替えます。注記はページといっしょに動きます
- **表の表示**: 共通ステータスの行の右端のスイッチで、注記一覧の表を隠せます(OFF)。図面が広く表示されます
- **保存**: 「保存」で `.annot` を書き出します。iPad では「ファイル」アプリのダウンロード先に入ります。Safari は同じファイルへの上書きができないため、同じ名前があると番号が付いた別ファイルになります(新しいほうを使ってください)
- **書き出し**: PNG(用紙設定つき)。iPad では「共有・写真に保存」と「ファイルとして保存」を選べます。全ページはZIPにまとめて出します
- **自動バックアップ**: 作業中の内容と図面を、ブラウザの中にも自動で保存します。ページが閉じても、開く前の画面の「前回の作業を復元」で戻せます(ファイルへの保存の代わりにはなりません)
- **大きい図面**: iPad のブラウザには、1枚の画像の大きさに上限があります。大きすぎる図面は、表示用の画像だけ縮小して持ち(座標は元の大きさのまま)、PNG書き出しは上限に収まるよう解像度(dpi)を自動で下げます。画面の下の欄に案内が出ます
- PDF の表示には、[PDF.js](https://mozilla.github.io/pdf.js/)(Apache License 2.0)を `web/lib/pdfjs/` に同梱しています

## 主な機能(Win版)

- PDF(複数ページ対応)・画像を背景に、〇付き番号と矢印を配置
- ダブルクリックで次の番号を自動配置(配置前は、マウスカーソルの代わりに、次に置かれる〇と番号が表示されます)。番号は後から変更でき、重複も可能
- 矢印の角度・長さ・太さを数値で管理。矢印の有無も後から切り替え可能
- **共通ステータス**(文字サイズ・矢印の長さ・矢印の太さ・数字色・〇の枠色・矢印色)を入力して「更新」を押すと、配置済みの注記も含めて一括反映
- **注記一覧(表)** で全ページの注記を確認・編集(「共通」「番号」の2列は横スクロールしても固定。「番号」の見出しを押すと昇順/降順に並べ替え。表と図面の境界をドラッグすると幅を変更)
  - 「共通」列をOFFにした注記は一括更新の対象から外れ、個別に編集できる
  - 表の行を右クリックして「下に行を挿入」(番号の重複などを作りやすくするため)
- 用紙(A4 / A3 / B4 / B5、縦横、余白、dpi)を選ぶと、画面に用紙枠を表示し、同じ設定でPNG書き出し
- 番号欄に「3,4」「3-5」と書くと、1つの〇に複数の番号を入れられる(1〜2桁は円、3桁以上や複数番号は横に長い楕円になる。矢印は楕円の縁から出る)
- 1つの〇に、矢印を何本でも追加できる(右クリック > 矢印を追加。図面でも表でも)。2本目以降は表の子行(└矢印2…)で、角度・長さ・太さ・色を持ち、「共通」ONなら共通ステータスに従う
- 矢印の選びやすさ: 選んでいる矢印の先端●・軸が最優先。重なって選べないときは、表の行を選ぶか、Alt+クリックで重なっている次の候補を選ぶ
- 表の上に「配置 / 未配置 / 重複 / 欠番」の集計を表示。重複する番号の行は黄色、未配置の行は灰色で、「状態」列にも表示
  - 欠番は、1から配置済みの最大の番号までの間で、どの注記にもない番号
- 「番号を振り直す」: 「欠番を詰める」(順序・重複はそのまま)、または「表の並び順に1から連番」を選べる
- 編集用ファイル(`.annot`、JSON形式)での保存・再編集

## 必要なもの(Win版をPythonで動かす場合)

- Python 3.9 以上(Tkinter が使える環境)
- Pillow
- PyMuPDF 1.x 系(PDFを開く場合。2.x は不要な大きな部品も一緒に入るため、1.x に固定しています)

```
pip install -r requirements.txt
```

## 起動(Win版)

```
python zumen_annot.pyw
```

Windows では `zumen_annot.pyw` をダブルクリックでも起動できます。
何も表示されずに終了する場合は、`zumen_annot_debug.bat` を実行すると、エラー内容が画面に表示されます。
エラーは `zumen_annot_error.log` にも記録されます。

## 使い方(Win版)

1. 「開く」で、PDF・画像、または編集ファイル(.annot)を選ぶ(「追加」で、あとから図面を最後に足せる。「編集」→「ページの入れ替え」で順番を変えられる)
2. 図面の空いている所をダブルクリックすると、次の番号で〇と矢印が置かれる(ダブルクリックの2回目を押したままドラッグすると矢印の向きが決まる)
3. 上部2段目の「共通ステータス」を変更して「更新」を押すと、共通がONの注記すべてに反映される
4. 右側の注記一覧で、行を選ぶと図面上の注記が強調される。「共通」をOFFにした行は、文字・長さ・太さ・色をダブルクリックで編集できる
5. 「保存」で `.annot` に保存、「PNG書き出し」で画像として出力
6. 共通ステータスの行の右端「表の表示」で、注記一覧を隠して図面を広く使える

### 主な操作

| 操作 | 内容 |
| --- | --- |
| ダブルクリック | 新しい番号を配置 |
| 注記をクリック | 選択(重なっているときは、選んでいる矢印が優先。Alt+クリックで次の候補) |
| 右クリック(図面・表) | 矢印を追加 / 矢印・注記を削除 |
| 〇をドラッグ | 注記の移動 |
| 矢印の軸をドラッグ | 矢印の向きを調整(長さはそのまま) |
| 矢印の先の ● をドラッグ | ●がマウスに付いてきて、向きと長さが変わる(共通ONの矢印は、離すと長さが共通値に戻る。Shiftで長さ固定) |
| 表で右クリック > 下に行を挿入 | 未配置の行を追加(番号を入力して図面をダブルクリックすると配置) |
| Ctrl + ホイール | 拡大縮小 |
| 右・中ボタンのドラッグ | 画面の移動 |
| PageUp / PageDown | PDFのページ送り |
| Delete / Esc | 削除 / 選択解除 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+S / Ctrl+E | 保存 / PNG書き出し |

## 編集ファイル(.annot)について

形式の詳しい仕様は [`docs/FORMAT.md`](docs/FORMAT.md) にあります(Win版・Web版で共通)。

- JSON形式で、背景の図面のパス、ページごとの注記、共通ステータス、用紙設定を保存します
- 図面そのもの(PDF・画像)は含まれません。`.annot` と同じ場所、または保存時のパスに図面が必要です
- 図面データや `.annot` を誤って公開しないよう、`.gitignore` で `*.annot` と `*.pdf` を除外しています
