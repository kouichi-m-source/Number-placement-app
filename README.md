# 番号配置アプリ

<img src="assets/icon.png" width="96" align="right" alt="番号配置アプリのアイコン">

図面(PDF・画像)の上に、〇付きの通し番号と矢印を配置するデスクトップアプリです(Python / Tkinter)。
配置した注記は編集可能なまま保存でき、必要なときだけ画像(PNG)として書き出せます。

## 主な機能

- PDF(複数ページ対応)・画像を背景に、〇付き番号と矢印を配置
- ダブルクリックで次の番号を自動配置(配置前は、マウスカーソルの代わりに、次に置かれる〇と番号が表示されます)。番号は後から変更でき、重複も可能
- 矢印の角度・長さ・太さを数値で管理。矢印の有無も後から切り替え可能
- **共通ステータス**(文字サイズ・矢印の長さ・矢印の太さ・数字色・〇の枠色・矢印色)を入力して「更新」を押すと、配置済みの注記も含めて一括反映
- **注記一覧(表)** で全ページの注記を確認・編集(「共通」「番号」の2列は横スクロールしても固定。「番号」の見出しを押すと昇順/降順に並べ替え。表と図面の境界をドラッグすると幅を変更)
  - 「共通」列をOFFにした注記は一括更新の対象から外れ、個別に編集できる
  - 表の行を右クリックして「下に行を挿入」(番号の重複などを作りやすくするため)
- 用紙(A4 / A3 / B4 / B5、縦横、余白、dpi)を選ぶと、画面に用紙枠を表示し、同じ設定でPNG書き出し
- 番号欄に「3,4」「3-5」と書くと、1つの〇に複数の番号を入れられる(1〜2桁は円、3桁以上や複数番号は横に長い楕円になる。矢印は楕円の縁から出る)
- 1つの〇に、矢印を何本でも追加できる(右クリック > 矢印を追加。図面でも表でも)。2本目以降は表の子行(└矢印2…)で、角度・長さ・太さ・色を持ち、「共通」ONなら共通ステータスに従う
- 矢印の選びやすさ: 選んでいる矢印の先端●・軸が最優先。重なって選べないときは、表の行を選ぶか、Alt+クリックで重なっている次の候補を選ぶ
- 表の上に「配置 / 未配置 / 重複 / 欠番」の集計を表示。重複する番号の行は黄色、未配置の行は灰色で、「状態」列にも表示
  - 欠番は、1から配置済みの最大の番号までの間で、どの注記にもない番号
- 「番号を振り直す」: 「欠番を詰める」(順序・重複はそのまま)、または「表の並び順に1から連番」を選べる
- 編集用ファイル(`.annot`、JSON形式)での保存・再編集

## 使い方

1. 「図面を開く」でPDFまたは画像を選ぶ
2. 図面の空いている所をダブルクリックすると、次の番号で〇と矢印が置かれる(ダブルクリックの2回目を押したままドラッグすると矢印の向きが決まる)
3. 上部2段目の「共通ステータス」を変更して「更新」を押すと、共通がONの注記すべてに反映される
4. 右側の注記一覧で、行を選ぶと図面上の注記が強調される。「共通」をOFFにした行は、文字・長さ・太さ・色をダブルクリックで編集できる
5. 「保存」で `.annot` に保存、「PNG書き出し」で画像として出力

### 主な操作

| 操作 | 内容 |
| --- | --- |
| ダブルクリック | 新しい番号を配置 |
| 注記をクリック | 選択(重なっているときは、選んでいる矢印が優先。Alt+クリックで次の候補) |
| 右クリック(図面・表) | 矢印を追加 / 矢印・注記を削除 |
| 〇をドラッグ | 注記の移動 |
| 矢印の軸をドラッグ | 矢印の向きを調整(長さはそのまま) |
| 矢印の先の ● をドラッグ | ●がマウスに付いてきて、向きと長さが変わる(共通ONの矢印は、離すと長さが共通値に戻る。Shiftで長さ固定) |
| 表で右クリック > 下に行を挿入 | 未配置の行を追加(番号を入力して図面をダブルクリックすると配置) |
| Ctrl + ホイール | 拡大縮小 |
| 右・中ボタンのドラッグ | 画面の移動 |
| PageUp / PageDown | PDFのページ送り |
| Delete / Esc | 削除 / 選択解除 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+S / Ctrl+E | 保存 / PNG書き出し |

## 必要なもの(Pythonで動かす場合)

- Python 3.9 以上(Tkinter が使える環境)
- Pillow
- PyMuPDF 1.x 系(PDFを開く場合。2.x は不要な大きな部品も一緒に入るため、1.x に固定しています)

```
pip install -r requirements.txt
```

## 起動(Pythonで動かす場合)

```
python zumen_annot.pyw
```

Windows では `zumen_annot.pyw` をダブルクリックでも起動できます。
何も表示されずに終了する場合は、`zumen_annot_debug.bat` を実行すると、エラー内容が画面に表示されます。
エラーは `zumen_annot_error.log` にも記録されます。

## 編集ファイル(.annot)について

- JSON形式で、背景の図面のパス、ページごとの注記、共通ステータス、用紙設定を保存します
- 図面そのもの(PDF・画像)は含まれません。`.annot` と同じ場所、または保存時のパスに図面が必要です
- 図面データや `.annot` を誤って公開しないよう、`.gitignore` で `*.annot` と `*.pdf` を除外しています
